# GitQuest

**Code. Play. Repeat.**

GitQuest is the home page for Hannah's YouTube channel, bringing coding projects and gaming adventures together in one place. Visitors can learn about the channel, choose a path, watch the featured video, and head to YouTube for more.

## What's on the site

- A welcoming landing page with links to the channel
- Separate sections for coding and gaming
- An introduction to Hannah
- An embedded featured YouTube video
- Responsive navigation with a toggleable mobile menu
- A custom 404 page styled to match GitQuest
